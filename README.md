# Fake News Detection using JavaScript

## Description

Fake News Detection is a machine learning project that classifies news articles as
REAL or FAKE based on their textual content. The project uses a simple Naive Bayes
text classification algorithm implemented in JavaScript.

## Features

- Detects whether news is REAL or FAKE
- Uses Natural Language Processing (NLP) techniques
- Implements Naive Bayes classification
- Easy to run using Node.js
- No external machine learning libraries required

## Technologies Used

- JavaScript
- Node.js
- Natural Language Processing
- Naive Bayes Classification
